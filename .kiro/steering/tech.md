# Technology

The current local application uses Python standard library HTTP and a limited read-only Modbus/TCP simulator/client, and a browser frontend without a build tool. Keep the backend bound to loopback, reject user-controlled network targets, and preserve structured protocol evidence. Run `python3 -m unittest discover -s backend/tests -v` from the project root. Treat this limited training transport as neither a production industrial stack nor safety-certified software.
