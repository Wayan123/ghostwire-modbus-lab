# Technology

The application uses ASP.NET Core and C# on .NET 8, a limited read-only Modbus/TCP simulator/client, and a browser frontend without a build tool. Keep the backend bound to loopback, reject user-controlled network targets, and preserve structured protocol evidence. Run `dotnet run --project csharp/GhostWire.Tests/GhostWire.Tests.csproj` from the project root. Treat this limited training transport as neither a production industrial stack nor safety-certified software.
