          Wire evidence (simulated frames)

          These are the exact bytes exchanged with the local simulator for this read, shown as hexadecimal. Move the pointer over a row, or Tab to it, to highlight its bytes.

          MBAP header
          The first 7 bytes of every Modbus TCP frame: transaction ID, protocol ID, length and unit ID.
          PDU
          Protocol data unit: the function code and its data, after the MBAP header.
          Unit ID
          The device address a gateway uses to route the request.
          Function code
          What the request asks for, for example 03 (read holding registers) or 04 (read input registers). An exception reply adds 80 hex to it.
