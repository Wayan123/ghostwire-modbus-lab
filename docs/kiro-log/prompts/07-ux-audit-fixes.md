Fix these issues found in a judge-style browser audit of release v1.0.0 (Windows Chrome, 1440 px and 360 px). Work as ghostwire-builder; follow the spec and steering. Read frontend/index.html, frontend/app.js, frontend/styles.css and the relevant C# first.

1. Phantom Writer is too easy to click through: each traffic-log row has a "Select" button that fills the answer form with that row's transaction ID and client. A learner can click rows until one verifies. Keep the log fully visible (client labels are legitimate capture metadata), but remove the per-row auto-fill "Select" buttons. The learner must type the transaction ID and client label. Keep keyboard access to rows. Also add a soft limit: after 3 wrong answers show a progressive hint (1st hint: "Look at the Function column: which entry changes data instead of reading it?"; 2nd hint: "Compare the value read before and after each entry."). Hints are training hints, labeled as such. No server change unless needed; if the server already tracks nothing, keep hint logic client-side.
2. favicon.ico returns 404 (console error). Add a small inline SVG favicon (ghost/wire motif, theme colors) via <link rel="icon" href="data:image/svg+xml,..."> or a frontend/favicon.svg file served by the existing static handler. No external assets.
3. Invalid inputs: typing unit ID 999 shows the browser validation message, but the status text still says "Read complete. Adjust a setting and retest to compare results." When a field is invalid, do not send the request; set aria-invalid on the field, focus it, and show a clear message in the test-message live region (e.g. "Unit ID must be 1–247. Nothing was sent."). Same for address, quantity, and scale.
4. On desktop at 1440 px, the traffic-log table is cramped: the Time column wraps into 3 lines and the Frames column is narrow. Improve layout: short time (HH:MM:SS, full ISO in a title/visually-hidden span), let the table scroll horizontally inside its container on small screens with a visible focusable region (role=region, aria-label, tabindex=0), and make the FC06 row visually distinct only AFTER a correct answer (keep existing behavior).
5. Add a tiny "Guided tour" for first-time judges: a dismissible banner at the top of the workspace, "New here? Start with The Silent Sensor, then try Phantom Writer," with a button that selects The Silent Sensor. It is remembered as dismissed in localStorage. Respect reduced motion.
