# Existing code and attribution

GhostWire was created for this exercise. Its implementation was authored here; no source code has been intentionally copied from MultiPoll Studio or multi-plc-agent. Those projects provided background experience only. The original planning PDF is alongside the repository and was used as a project brief. The initial Python implementation, created during this project, was replaced by the C# implementation; its historical evidence remains labeled in `verification.md`.

The application uses ASP.NET Core and a small purpose-built, read-only Modbus/TCP implementation. It is not a maintained general-purpose Modbus library; its narrow scope and testing limits must be disclosed. .NET and platform dependencies retain their respective licenses. Apache-2.0 is the selected project license. Review source and asset provenance before public release.
