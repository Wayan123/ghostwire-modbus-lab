# Existing code and attribution

GhostWire is a new local project created for this exercise. Its application implementation was authored here; no source code has been intentionally copied from MultiPoll Studio or multi-plc-agent. Those projects provided background experience only. The original planning PDF is outside this repository, alongside the `ghostwire` directory, and was used as a project brief.

The application currently uses Python's standard library and a small purpose-built, read-only Modbus/TCP implementation. It is not the recommended maintained general-purpose Modbus library; its narrow scope and testing limits must be disclosed. Python and any other platform dependencies retain their respective licenses. Apache-2.0 is the selected project license. Review all source and asset provenance before public release.
